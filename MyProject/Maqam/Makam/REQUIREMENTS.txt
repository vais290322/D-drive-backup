# Maquam Holidays - System Requirements

## System Requirements

### Operating System
- macOS 10.15 or later
- Ubuntu 20.04 LTS or later
- Windows 10 or later
- Any Linux distribution with systemd support

### Software Requirements

#### Node.js
- Version: 18.x or higher (20.x recommended)
- Download: https://nodejs.org/
- Verify: `node -v` should show v18.0.0 or higher

#### MongoDB
- Version: 6.0 or higher (7.0 recommended)
- Download: https://www.mongodb.com/try/download/community
- Verify: `mongosh --version` should show 2.x.x or higher

#### Package Manager
- pnpm (recommended): `npm install -g pnpm`
- OR npm: Comes with Node.js
- Verify: `pnpm -v` or `npm -v`

### Hardware Requirements

#### Minimum
- CPU: 2 cores
- RAM: 4 GB
- Storage: 10 GB free space
- Network: Broadband internet connection

#### Recommended
- CPU: 4 cores or more
- RAM: 8 GB or more
- Storage: 20 GB free space (SSD recommended)
- Network: High-speed broadband

## Environment Variables Required

### MongoDB Configuration
```
MONGODB_URI=mongodb://localhost:27017/maquam_holidays
```

### Server Configuration
```
PORT=5000
NODE_ENV=development
CLIENT_URL=http://localhost:5173
```

### JWT Configuration
```
JWT_SECRET=<minimum-32-characters-secret>
```

### Razorpay Configuration
```
RAZORPAY_KEY_ID=rzp_test_xxxxxxxxxx
RAZORPAY_KEY_SECRET=<your-secret>
```

### Frontend Configuration
```
VITE_API_URL=http://localhost:5000/api
VITE_RAZORPAY_KEY_ID=rzp_test_xxxxxxxxxx
VITE_APP_ID=app-8farl2rn17nl
VITE_API_ENV=development
```

## Security Requirements

### SSL/TLS
- TLS 1.2 or higher
- Valid SSL certificate
- HTTPS enforced

### Authentication
- JWT tokens with secure secret (64+ characters)
- Password hashing with bcrypt (10+ salt rounds)
- Secure cookie settings (httpOnly, secure, sameSite)

### Database
- MongoDB authentication enabled
- Strong database password
- Network access restrictions
- Regular backups

### API Security
- CORS properly configured
- Rate limiting (recommended)
- Input validation
- SQL injection prevention (via Mongoose)
- XSS protection

## Performance Requirements

### Response Times
- API endpoints: < 200ms (average)
- Page load: < 2 seconds (first load)
- Page load: < 500ms (subsequent loads)

### Concurrent Users
- Development: 10-50 users
- Production: 1000+ users (with proper scaling)

### Database
- Connection pooling enabled
- Indexes on frequently queried fields
- Query optimization

## Backup & Recovery

### Database Backup
```bash
# Backup
mongodump --uri="mongodb://localhost:27017/maquam_holidays" --out=/backup/path

# Restore
mongorestore --uri="mongodb://localhost:27017/maquam_holidays" /backup/path/maquam_holidays
```

### Backup Schedule (Recommended)
- Daily: Automated backups
- Weekly: Full system backup
- Monthly: Archive backups
