## Responsive Behavior

### Desktop (XL - 1280px+)
- 3-column layout
- Left column: 2/3 width (all information cards)
- Right column: 1/3 width (photo + quick actions)
- 2-column grids within cards

### Tablet (MD - 768px to 1279px)
- 2-column layout
- Information cards stack vertically
- 2-column grids within cards maintained
- Photo and actions move to top or bottom

### Mobile (< 768px)
- Single column layout
- All cards stack vertically
- Single column within cards
- Full-width buttons and inputs
- Optimized spacing for touch

## Color Coding

### Text Colors
- **Labels:** Muted foreground (gray)
- **Values:** Default foreground (black/white)
- **Financial Data:** Success color (green)
- **Icons:** Muted foreground (gray)

### Background Colors
- **Cards:** Card background (white/dark)
- **Account Cards:** Muted background (light gray)
- **Badges:** Variant-based (default/destructive)

### Status Indicators
- **Active:** Default badge (blue/green)
- **Inactive:** Secondary badge (gray)
- **Deposit:** Success color (green)
- **Withdraw:** Destructive color (red)

## Data Display Rules

### Conditional Rendering
- Sections only appear if data exists
- Empty fields are hidden
- No "N/A" or placeholder text
- Clean, minimal display

### Text Formatting
- **Names:** Title case
- **Gender/Status:** Capitalized
- **Numbers:** Monospace font for IDs
- **Currency:** Indian format (₹10,00,000)
- **Dates:** MMM DD, YYYY format

### Field Validation
- All fields are optional (nullable)
- No required fields for display
- Graceful handling of missing data
- Type-safe implementations

## User Actions Available

### Primary Actions
1. **Edit Customer** - Navigate to edit form
2. **Make Deposit** - Go to deposit page
3. **Make Withdrawal** - Go to withdraw page
4. **View Statement** - Open account statement

### Secondary Actions
1. **Back to Customers** - Return to customer list
2. **View Account Details** - Click on account card
3. **View Transaction** - Click on transaction row

## Technical Implementation

### Component Structure
```typescript
CustomerDetails.tsx
├── Header (Back button, Title, Edit button)
├── Main Grid (3 columns on XL)
│   ├── Left Column (2/3 width)
│   │   ├── PersonalInfoCard
│   │   ├── ContactInfoCard
│   │   ├── AddressInfoCard
│   │   ├── ProfessionalInfoCard
│   │   ├── KYCInfoCard
│   │   ├── AlternateBankCard (conditional)
│   │   ├── AccountsCard
│   │   └── TransactionsCard
│   └── Right Column (1/3 width)
│       ├── PhotoCard
│       └── QuickActionsCard
```

### Data Flow
```
URL Param (id) 
  → useEffect 
    → loadCustomer() 
      → getBankCustomerById(id) 
        → setCustomer(data)
          → Render all sections
```

### Styling Approach
- Tailwind CSS utility classes
- shadcn/ui components
- Responsive breakpoints (md, xl)
- Conditional rendering with &&
- Grid layouts for organization

**Note:** This visual guide represents the enhanced customer profile page. All sections are conditionally rendered based on available data, ensuring a clean and professional presentation.
